# PC完結で月50万円を目指すプロジェクト

ゴール: **PCだけで完結する仕事で月50万円の利益を出し、最終的には独立・法人化も選べる状態にする。**

---

## 0. 前提と現実ライン

- 副業で月50万は「上位数%」の水準。**12〜24ヶ月**で到達する計画を立てる。
- 稼働時間の目安は **週15〜20時間**（平日1.5h＋土日5h程度）。
- 「時給×時間」だけでは月50万に届きにくい。**単価アップ**と**ストック収益（継続契約・自社商品）**を早めに混ぜる。
- 避けるもの: 高額な情報商材・塾、FX/仮想通貨の「自動売買ツール販売」、MLM、「スマホで日給◯万」系。投資やトレードは「収入源」ではなく余剰資金の運用として別扱いにする。

## 1. 戦略: 「受託で稼ぎながら、顧客の困りごとを商品化する」

| フェーズ | 期間 | 主な収入源 | 月の目標 |
|---|---|---|---|
| 1. 初収益 | 0〜3ヶ月 | クラウドソーシングで小さな受託（自動化・制作） | 5〜10万 |
| 2. 単価アップ | 3〜9ヶ月 | 直接契約・継続保守・実績を使った高単価案件 | 20〜30万 |
| 3. 商品化 | 6〜18ヶ月 | 繰り返し出てきた依頼をテンプレ/ツール/SaaS化 | 50万〜 |
| 4. 独立判断 | 12〜24ヶ月 | 3ヶ月連続で本業手取り超え → 独立・法人化を検討 | 本業超え |

### なぜこの順番か
- 受託は**最速で現金化**でき、かつ「お金を払ってでも解決したい課題」を実地で学べる。
- いきなり自社商品を作ると、売れるかどうか分からないまま時間が溶けやすい。
- AI（Claude Code など）を使えば、1人で受託・開発の生産性を数倍にできる。これが最大のレバレッジ。

## 2. 具体的な稼ぎ方の候補（PC完結）

スキル別に、最初の一歩として現実的なもの。

| 区分 | 内容 | 単価目安 | 立ち上がり | ストック性 |
|---|---|---|---|---|
| **業務自動化（おすすめ）** | Excel/スプレッドシート集計、GAS、Python、RPA、API連携、AIチャットボット導入 | 3〜30万/件 | 速い | 保守契約で◯ |
| Web制作 | LP・コーポレートサイト（WordPress/Studio等） | 5〜30万/件 | 普通 | 保守・更新で△ |
| AI導入支援 | 中小企業向けのChatGPT/Claude活用設計・研修・社内ツール化 | 5〜50万/件 | 普通 | 顧問契約で◎ |
| デジタル商品 | Notion/スプレッドシートテンプレ、GASツール、プロンプト集（note, BOOTH, Gumroad） | 500〜1万円/個 | 遅い | ◎ |
| マイクロSaaS / Chrome拡張 / LINEボット | 特定業界の小さな課題を月額課金で解決 | 500〜5,000円/月×人数 | 遅い | ◎◎ |
| コンテンツ | ブログ・note・YouTube（上記の集客装置として） | 広告/アフィリエイト | かなり遅い | ◎ |

**推奨ルート:** 業務自動化 or AI導入支援で受託 → 同じ業界・同じ依頼が3回来たらテンプレ化/SaaS化 → 発信（実績記事）で直接依頼を増やす。

## 3. 月50万の内訳イメージ（例）

| 収入源 | 計算 | 月額 |
|---|---|---|
| 継続保守・顧問 | 5社 × 4万円 | 20万 |
| 単発の受託開発 | 1〜2件 × 10万円 | 15万 |
| 自社ツール/SaaS | 150人 × 1,000円 | 15万 |
| **合計** | | **50万** |

受託だけで50万を作るより、**保守・顧問・月額課金**の比率を上げるほど安定し、独立もしやすくなる。

## 4. 最初の2週間でやること

- [ ] 本業の就業規則で副業可否と申請要否を確認する
- [ ] 自分の得意分野を3つ書き出す（本業の業界知識も武器になる）
- [ ] 取り組む領域を1つに決める（迷ったら「業務自動化」）
- [ ] ポートフォリオ用の作品を2〜3個作る（例: 請求書自動作成GAS、問い合わせ自動返信ボット）
- [ ] クラウドワークス / ランサーズ / ココナラ に登録し、プロフィールと出品ページを作る
- [ ] 毎日3件、案件に提案する（提案文テンプレを作って改善し続ける）
- [ ] [`tracker/kpi.csv`](tracker/kpi.csv) に毎週の数字を記録する

## 5. 追うべき数字（KPI）

- 週の提案数 → 受注率 → 平均単価 → 実効時給（売上 ÷ 作業時間）
- 継続契約の社数 / 月額課金の利用者数（＝ストック収益）
- 実効時給が3,000円を超えたら単価を上げる。5,000円を超えたら商品化に時間を回す。

## 6. お金・手続きのチェックポイント

- **住民税**: 副業バレが気になるなら、確定申告で住民税を「自分で納付（普通徴収）」にする。
- **確定申告**: 会社員は副業の所得が年20万円を超えたら必要（住民税は20万以下でも申告が必要）。
- **開業届＋青色申告**: 継続的に事業として行うなら提出し、最大65万円控除を狙う（帳簿付けが前提）。
- **インボイス**: 法人客が増えたら登録を検討。売上1,000万円超で消費税の課税事業者。
- **法人化の目安**: 利益（所得）がおおむね年800万円前後を超えたら税理士に相談。
- ※税制は変わるので、具体的な判断は最新情報・税理士で確認すること。

## 7. 独立の判断基準

以下をすべて満たしたら独立を検討する。

1. 副業収入が**3ヶ月連続で本業の手取りを超えている**
2. 収入の半分以上が継続契約・月額課金（ストック）
3. 生活費の6〜12ヶ月分の貯金がある
4. 取引先が1社に依存していない（最大でも売上の40%以下）
