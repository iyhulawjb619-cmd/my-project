## 設計内で見つかった追加の矛盾（critic.contradictions、未解決）

- market_sessions.py の値動きラベル既定「静か <25／普通 25〜75／荒い >75」は、欧州前レポートの観測「24 → 普通」と整合しない。
- tug_of_war.py の株 ● 既定「|%| ≥ 0.5 → ●」は、NY 版の観測「NAS100 −0.52% は中立」と矛盾（日経 −0.33% 中立・−1.79% ● とのみ整合）。
- correlation.py 内で相場全体評価の算出が二重定義（outputs「6 時間足の多数決」vs thresholds「日足・4 時間足・1 時間足の 3 値多数決」）。
- position_sizing.py の「ロット目安 = 必要資産 × 2% ÷ (60 × 0.01)」は 2% を固定使用だが、pre_entry.py の DISCRETIONARY_RISK_PCT 既定は 0.5（案 2.0）で、#1 を未決としながら式側で 2% を既定化している。
- f4_rules.py の features「見送り（F4 の判定）」は抽出した機能一覧に存在しない（出所は用語集のみ）。
- 週次レポートのジョブ時刻: API/jobs 拡張は「日曜 00:30」、資料は月曜 00:45 JST 作成。
- event_windows.py の thresholds は早朝帯既定を「08:15」と断定しているが conflicts では未決。東京前版の早朝帯は 06:45 開始だが thresholds は終了時刻のみ扱い開始 05:45 として一元化。
- 「重要度 3 = 赤枠」「重要度 2 = 黄」「雇用統計 −45/+60」と、NY 版 HTML で指標帯が黄 class である事実が併存。
