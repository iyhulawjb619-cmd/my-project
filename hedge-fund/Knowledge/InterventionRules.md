# 為替介入アラート（介入警戒段階 1〜5）の既定ルール・警戒水準・過去実績

対象コード: app/intervention.py（regime.py 相当）。
出所: tokyo_report.html／europe_report.html／ny_report.html の「⑰ 為替介入アラート」、weekly_report.html「今週の警戒事項」、mandala.md [⑤-6]、用語集。
資料の regime.py は**計算式未記載**。本書の段階決定ルールは資料に出る根拠 3 点から再構成した既定であり、ユーザーの regime.py（needs_user_data）で置き換える。

## 1. 段階の意味（資料）

| 段階 | 意味 |
|---|---|
| 1〜2 | 低い（資料に明示なし。1〜5 にクランプ） |
| 3 | 平常（資料の全版で 3/5 = 平常） |
| 4・5 | 警戒が強い。5 が最も高い |

「介入 = 円安を止める政府の円買い」。警戒フラグ（ヘッダ）は「介入警戒段階が高い場合（4・5）」と「±1.5% を超えたペアの有無」「昨日／今日のドル円変化率」「直近 24 時間の 15 分の極端な動き（異常判定ペア）」で立てる。フラグ水準名（注意／無）の決定条件は資料に明示なし。

## 2. 5 段階の既定ルール（決定論、仮置き）

```
level = 3                                              # 平常
+1  if (20 日高値 − 現在値) <= ATR14 × 0.5             # 高値に接近
+1  if 現在値 >= 介入警戒水準の下限 (159.50)             # 警戒水準到達
+1  if 14 日以内の要人発言に「高い緊張感」「注視」級の口先介入、または財務省レートチェック報道
−1  if (20 日高値 − 現在値) >= ATR14 × 3               # 高値から十分離れている
level = clamp(level, 1, 5)
signature_detected = anomaly.intervention_signature     # 段階に関わらず「介入らしい形」フラグ
```

- 距離閾値 ATR×0.5／ATR×3 は仮置き（資料に無い）。設定で変更。
- 出力: InterventionAlert(level 1-5, gauge_on = level, reasons[], distance_to_high20, signature_detected, high_zone_buy_warning)。
- 根拠の箇条書き 3 行（資料の構成）: 直近の円クロス同時急落の有無 ／ 20 日高値までの距離 ／ 過去の介入実績。
- Market Regime Agent の details に「介入警戒段階」を追加し、risk.py の reasons にも流す（段階 4・5 で Event Risk 相当の注意）。

## 3. 介入シグネチャ（自動検知）

円がらみ 3 ペアが同時に −30 pips 以上急落したら「介入らしい形」として検知（全版共通、anomaly.py）。
観測例: 10/30 12:00 に円クロス 3 ペアが同時に約 −40p（日銀の発表時刻と同じ）。介入の報道はなし → シグネチャは「形」の検知であり原因の証明ではない。

## 4. 警戒水準

| 項目 | 値 | 出所 |
|---|---|---|
| 介入警戒水準 | 159.50〜160 円（先週の高値 158.35 の上） | 週次レポート「円安が進んだ場合の介入警戒」 |
| 高値圏の買い回避 | 158〜160 円では買わない | 曼荼羅 [⑤-6]、実績 −67,226 円 |
| 20 日高値（観測） | 158.95（11/2 時点で約 1.1 円、11/4 約 0.3 円、11/5 約 0.55 円の距離） | 各版の ⑰ |
| 実弾介入の観測 | なし（11/2 時点） | 週次 |

設定キー: `intervention_watch_zone = (159.50, 160.00)`、`high_zone_no_buy = (158.00, 160.00)`。水準は相場で変わるため、本ファイルの値を更新して運用する（コードに埋め込まない）。

## 5. 要人発言（14 日以内のみ採用）

- 10/28 片山財務相「市場の動向を高い緊張感を持って注視」（定点レポート経由、週次・NY 前で引用）。
- 要人発言は 14 日より古いものは載せない（全版共通）。段階判定の +1 条件にも同じ鮮度フィルタを使う。

## 7. ⑰ セクションの出力形式

```
⑰ 為替介入アラート  段階 n/5  ●●●○○
・<直近の円クロス同時急落の有無>（例: 10/30 12:00 に円クロス 3 ペアが同時に約 −40p。介入の報道はなし）
・20 日高値 <値> まで約 <差> 円
・<過去の介入実績>（例: 4〜5 月に 11 兆円超の円買い介入（共同 7/17））
読み方: 介入 = 円安を止める政府の円買い。段階 3 は平常、4・5 で警戒が強い
```

段階は「起こりやすさの目安」で、方向の予想ではない。買うか売るかはこのレポートでは扱わない。

## 8. 裁量規則との接続

- 日銀会合日と介入の日は建玉を週末に持ち越さない・新規を見送る（改善策 5）。pre_entry の `ev=boj` は「日銀会合日・介入の日」を同じ stop として扱う。
- 介入の日の判定 = signature_detected または level ≥ 4（既定）。
