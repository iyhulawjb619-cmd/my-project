# 請求書自動作成ツール（Googleスプレッドシート版）

明細を入力してボタンを1回押すだけで、取引先ごとに次の3つを自動で行います。

1. インボイス制度に対応した請求書PDFを作る（登録番号、税率ごとの消費税、軽減税率の※印）
2. Googleドライブに保存する
3. Gmailに下書きを作る（設定で「すぐ送信」にも変更できます）

月末の請求作業が「1社10分」から「全社まとめて1分」になります。

---

## 導入手順（購入者向け・約5分）

1. 配布されたスプレッドシートのリンクを開き、**「コピーを作成」**を押す
2. コピーしたスプレッドシートを開き、上部メニュー **「請求書 → 初期セットアップ」** を押す
   - 初回だけGoogleの許可画面が出ます。「詳細 → （安全ではないページ）に移動 → 許可」を押してください
   - ※スクリプトはあなたのGoogleアカウントの中だけで動きます。外部にデータは送りません
3. 「設定」シートに自社名・住所・登録番号・振込先を入力する
4. 「取引先」シートに請求先を登録する
5. 「明細」シートに当月の作業や商品を入力する
6. メニュー **「請求書 → 請求書を作成」** を押す → 請求月を入れてOK

## 設定項目

| 項目 | 説明 |
|---|---|
| 支払期限 | `1` なら翌月末、`0` なら当月末、`2` なら翌々月末 |
| 処理方法 | `下書き`（おすすめ）/ `送信`（すぐにメール送信）/ `PDFのみ` |
| 保存先フォルダID | 空欄なら初回に「請求書PDF」フォルダを自動で作ります |
| メール件名・本文 | `{取引先名}` `{担当者名}` `{請求月}` `{合計}` `{支払期限}` `{請求書番号}` `{自社名}` が使えます |

## よくある質問

- **同じ明細を二重に請求してしまわない？** → 作成済みの明細には請求書番号が書き込まれ、次からは対象外になります。作り直すときは、その番号を消してから実行してください。
- **8%と10%が混ざっていても大丈夫？** → 税率ごとに合計してから消費税を計算します（端数は切り捨て）。インボイスの記載要件に沿った形式です。
- **数量に小数は使える？** → 使えます（例: 2.5時間）。金額は1円未満を四捨五入します。

## 開発者向け

- `src/Code.gs` … メニュー、シートの読み書き、PDF作成、Gmail処理
- `src/Calc.gs` … 計算と整形の関数（Googleの機能を使わないので、Nodeでテストできます）
- テストの実行: リポジトリ直下で `npm test`
- 配布用シートの作り方: 新しいスプレッドシートを作る → 拡張機能 → Apps Script → `Code.gs` と `Calc.gs` を貼り付ける → `setup` を実行する → サンプルの値を残したまま共有リンクを「閲覧者」で発行し、URL末尾の `/edit...` を `/copy` に変える
