# 提案文テンプレート（クラウドワークス / ランサーズ）

受注率を上げるコツ:
- **最初の2行で「依頼内容を理解していること」を示す**（募集文の言葉を使う）
- 実現方法を具体的に1〜3行で書く → 相手が「この人に任せれば大丈夫」と感じる
- 質問を1つ入れる → 返信をもらいやすくなる
- 文章は短めにする（スマホで読まれる前提）

案件の募集文を Claude に貼り付けて「proposal-templates.md の形で提案文を作って」と頼めば、そのまま使える提案文を作ります。

---

## 汎用（自動化・ツール作成系）

```
【クライアント名】様

はじめまして、【名前】と申します。
「【募集文にある課題をそのまま引用】」を自動化したい、という件で提案させてください。

■ 実現方法（案）
【例：フォームの回答をトリガーにGASでスプレッドシートへ整形・転記し、
担当者へGmailで自動通知します。手作業はゼロになります。】

■ 近い実績
請求書の自動作成ツール（スプレッドシート＋GAS、インボイス対応）を作り、
販売しています。【URL】

■ 納期・費用
・納期：着手から【5】日
・費用：【◯◯】円（納品後14日間は無料で修正します）

■ 1点確認させてください
【例：現在お使いのシートを、サンプルデータに差し替えて共有いただくことは可能でしょうか？】

ご検討よろしくお願いいたします。
```

## Webサイト・LP制作系

```
【クライアント名】様

はじめまして、【名前】です。
【業種】向けのLP制作の件、「【ターゲット】に【目的：問い合わせ増加など】」という
ゴールに合わせた構成でご提案いたします。

■ 進め方
1. ヒアリング（30分のオンライン or チャット）
2. 構成案・ワイヤーフレームの提出（2日）
3. デザイン・実装（5日）→ 修正2回まで無料

■ 費用・納期
【◯◯】円／ 約【10】日

■ 確認したいこと
すでに使いたい写真やロゴはお持ちでしょうか？

よろしくお願いいたします。
```

## 単価アップ交渉（継続案件の3回目以降）

```
いつもありがとうございます。
これまで【◯件】担当させていただき、【成果：工数◯時間削減など】につながりました。

今後、【追加の価値：保守対応・改善提案】も含めてお手伝いしたく、
次回から【新単価】、または月額【◯◯】円の保守契約という形で
ご相談させていただけないでしょうか。
```
